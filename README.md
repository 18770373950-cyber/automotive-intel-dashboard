# automotive-intel-dashboard

## 发布前数据校验

每次修改 `data.js` 后，必须先运行：

```bash
node scripts/validate-data.js
```

校验覆盖全局 ID、seedId、模块归属、必填字段、日期与来源格式、每日20条行业热点与20条热点新车、两类资讯均含当天内容、日报同事件重复、发布会日历精确重复及跨车型复制污染。GitHub Actions 会在每次提交到 `main` 时重复执行校验。

当前页面依次提供总览、汽车行业资讯、汽车资讯池和车企发布会日历。行业资讯固定20条行业热点，资讯池固定20条热点新车；普通定档、预售和上市节点进入发布会日历，避免重复挤占资讯名额。

页面数据版本递增时，浏览器会自动刷新官方数据并清理已停用模块的本地缓存。
