# automotive-intel-dashboard

## 更新范围（2026-10-27起）

用户最新要求：在线汽车看板只维护车企发布会日历。`daily` 和 `dailyArchive` 保留现有内容，停止刷新或追加；不得更改旧资讯的日期制造新鲜度。资讯冻结时间与完整性摘要记录在 `update-policy.json`，只有用户明确要求恢复资讯更新时才能调整冻结规则。

后续更新仅追加/核验 `calendar` 发布、首秀、预售、上市、交付和技术活动节点，并更新必要的版本、更新时间与截止说明。保留同车型全部历史状态及分项价格；不得删除历史记录。截止说明改为日历更新摘要，不再要求新增40条资讯。

当天及前一天的汽车行业热点改由聊天中的独立午报任务推送，计划每日北京时间12:00。该任务不写入本站。原先暂停的看板自动任务继续保持暂停，手动更新按用户请求执行。

## 发布前数据校验

每次修改 `data.js` 后，必须先运行：

```bash
node scripts/validate-data.js
```

校验覆盖全局 ID、seedId、模块归属、必填字段、日期与来源格式、资讯冻结基线完整性、日报同事件重复、过期日历状态闭环、发布会日历精确重复及跨车型复制污染。冻结资讯保留20条行业热点与20条热点新车，不要求包含日历更新当日的新资讯。GitHub Actions 会在每次提交到 `main` 时重复执行校验。

当前页面依次提供总览、汽车行业资讯、汽车资讯池和车企发布会日历。两个资讯入口作为历史内容保留，后续新节点仅进入发布会日历。

页面数据版本递增时，浏览器会自动刷新官方数据并清理已停用模块的本地缓存。
